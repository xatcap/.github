# xatcap

> xatcap is a suite of tools that provide the building blocks for creating AI-powered systems and workflows.

## Overview

xatcap is a suite of tools that provide the building blocks for creating AI-powered systems and workflows. The main focus is to work efficiently with small, offline models while offering the flexibility to work with bigger ones / cloud as well.

All sub-systems are fine-tuned to work with small LLMs, and the main philosophy of the project revolves around burning tokens where it actually matters while utilizing runtime solutions, determinism and sophisticated algorithms where it fits.

## Features

- Build RAGs easily.
- Quickly integrate local LLMs without any additional installations.
- Create your own AI powered systems and workflows in an easy and flexible way.
